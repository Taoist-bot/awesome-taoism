# Contributing to Awesome Taoism

Thank you for your interest in contributing! This list aims to be a comprehensive, respectful resource for anyone interested in Taoism.

## Guidelines

1. **Quality over quantity** — Only suggest resources you've personally used or thoroughly researched.
2. **Respectful tone** — Taoism is a living spiritual tradition. Treat all resources and practitioners with respect.
3. **No spam** — Commercial links are welcome if they provide genuine value, but no pure advertising.
4. **Bilingual preferred** — Resources available in both Chinese and English are especially valuable.
5. **Verify links** — Make sure all links are working before submitting.

## How to Contribute

1. Fork this repository
2. Add your resource to the appropriate section in `README.md`
3. Follow the existing format and style
4. Submit a pull request with a clear description

## Format

For new entries, follow this pattern:

```markdown
- [Resource Name](https://example.com) — Brief description of what it offers.
```

For tools:

```markdown
| Tool Name | Description | [Link](https://example.com) |
```

## Sections

If your resource doesn't fit an existing section, feel free to propose a new one in your pull request.

## Code of Conduct

- Be inclusive and welcoming
- Respect different schools and interpretations of Taoism
- No political or controversial content unrelated to Taoism
- Focus on educational and spiritual value

Thank you for helping make this resource better for everyone! 🙏
